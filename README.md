# 🌍 Luxo Travel

Luxo Travel is a modern, responsive travel website built with React.js and SCSS. It offers users a seamless and visually engaging way to explore and plan trips to the world’s most beautiful destinations.

![Luxo Travel Preview](./preview.png)

## ✨ Features

- 🎥 Full-screen video background with smooth overlays
- 🗺️ Destination cards with country flags and descriptions
- 🔍 Interactive search bar with filters (location, date, price)
- 💎 Luxury travel theme with elegant animations
- 📱 Fully responsive design (mobile, tablet, desktop)
- 📦 Modular, clean React components and SCSS styling
- 🧭 Scroll animations powered by AOS (Animate on Scroll)

## 🚀 Technologies Used

- **React.js**
- **SCSS / CSS Modules**
- **AOS Library**
- **React Icons**
- **Google Fonts**
